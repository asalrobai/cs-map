# 🗺️ خارطة علوم الحاسب

موقع عربي تفاعلي يشرح جميع فروع علوم الحاسب: المتطلبات، مسار التدرج، أفضل المصادر، والوظائف — مع صفحة استفسارات.

**المعاينة:** https://asalrobai.github.io/cs-map/

## التشغيل محلياً
افتح `index.html` في المتصفح مباشرة — لا يحتاج سيرفر.

## النشر على GitHub Pages
الموقع ملف واحد `index.html` في الجذر، جاهز للنشر من فرع `main`.
